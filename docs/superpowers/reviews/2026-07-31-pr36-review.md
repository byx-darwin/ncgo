## Important finding (found & fixed)

- **FailOpen lost last-known-good after a 2nd consecutive refresh failure.** The refresh error path preserved the good value only when `prev.err == nil`; on a 2nd consecutive failure it overwrote it with empty, so the default FailOpen silently degraded to an empty pool — violating the documented contract. **Fix (`4e3da15`):** added `hasValue bool` to `cacheEntry`; refresh preserves on `prev.hasValue`; `applyPolicy` uses `entry.hasValue`. Two regression tests added; pre-fix they fail exactly as described, post-fix 16/16 `-race` pass. Re-reviewed: FIX APPROVED. (The stale golden `infra-canary/ops.go` was re-recorded after the fix.)
