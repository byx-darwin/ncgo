## Framing correctness (`readFrame`, `writeFrame`, `EncodeMessage`)

- Normal line: returned after `TrimRight(line, "\r\n")` (CRLF-tolerant).
- Blank lines: skipped, loop continues.
- EOF without trailing newline: the trimmed-non-empty check precedes the error check, so the final message is delivered and EOF surfaces on the next call → `Serve` returns `nil` cleanly.
- Malformed line: returned by `readFrame`, `json.Unmarshal` fails in `Serve`, `continue` skips it without killing the loop.
- `writeFrame`/`EncodeMessage`: `json.Marshal` emits single-line JSON, one `Write` of `body + '\n'` — no interleaving, no header residue.
- `DecodeResponses` delegates to the same `readFrame`, so decoder and server cannot drift.
